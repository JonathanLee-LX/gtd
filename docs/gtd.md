# GTD 用法约定

本仓库**不**单独建「情境」字段。需要按「我现在在哪 / 能干什么」挑任务时，用普通标签，名字以 `@` 开头即可。

## 情境标签

推荐（可按需增删，标签名即约定）：

| 标签 | 含义 |
|---|---|
| `@电脑` | 需要电脑、网络、深度专注 |
| `@出门` | 外出、办事、跑腿 |
| `@电话` | 打电话、语音沟通 |

任务详情里添加标签时输入 `@电脑`（不要做成独立字段）。列表上点标签，或打开搜索页用标签筛选，即可只看当前情境下的任务。

## 筛选

- 网页：任务行上的 `#标签` → 搜索页 `?tagId=…`；搜索页也可用标签筛选条。
- API / MCP：`list_tasks` / `search_tasks` 的 `tagId`（与网页同一套过滤）。

## 非目标

- 不新增 schema 字段、不做迁移
- 不自动从标题/备注推断情境
